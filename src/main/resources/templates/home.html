Application de démonstration

Cette application démontre les concepts fondamentaux de Spring MVC : Contrôleurs, Modèles, Vues et leur interaction.

Architecture MVC

Séparation claire entre Modèle, Vue et Contrôleur pour une architecture maintenable.

Contrôleurs Spring

Utilisation des annotations @Controller, @GetMapping, @PostMapping pour gérer les requêtes.

Templates Thymeleaf

Vues dynamiques avec Thymeleaf pour un rendu côté serveur moderne et élégant.

À propos de cette application
Concepts démontrés :
  • Modèle (Model) : Classe Task représentant les données
  • Vue (View) : Templates Thymeleaf pour l'affichage
  • Contrôleur (Controller) : HomeController et TaskController
  • Service Layer : TaskService pour la logique métier
  • Injection de dépendances : @Autowired
  • Mapping d'URL : @GetMapping, @PostMapping, @PathVariable
  • Binding de données : @ModelAttribute
